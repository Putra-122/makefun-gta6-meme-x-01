A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty: the make.fun ghost rides in the back seat with a bag of USDC while Lucia and Jason drive through Vice City — "MY AGENT PAID FOR GTA 6 BEFORE I FINISHED DOWNLOADING IT". The meme is posted on X from a public account with make.fun and the entrant's play code in the post's text; POST.json hands in the post's address. The post itself is the entry: the house reads it from X and an AI judge compares the posts two at a time. Top 50 share $500.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this directory's `POST.json`. Replace the placeholder URL in POST.json with the real post address (`https://x.com/<handle>/status/<id>`) after posting.
